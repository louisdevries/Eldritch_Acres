# 🌿 Eldritch Acres

A farming simulation game with eldritch horror elements, where crops are not just plants… but living, reactive entities.

---

## 🌱 About the Game

*Eldritch Acres* is a prototype Unity project that blends cozy farming mechanics with unsettling, evolving biological anomalies.

You manage a farm where crops may:
- React to the player’s presence
- Exhibit autonomous behaviour
- Defend, flee, or spread corruption
- Evolve into unpredictable forms over time

---

## 👁️ Core Concepts

- 🌽 **Living Crops** — Plants that behave like entities, not objects  
- 🧠 **Reactive World** — The farm responds dynamically to player actions  
- 🌫️ **Corruption System** — Areas and crops can become infected or altered  
- ⚙️ **Emergent Behaviour** — Simple rules creating complex, unpredictable outcomes  

---

## 🧪 Example Crop Ideas

- 🌽 **Sentinel Corn** — Watches the player and alerts nearby crops  
- 🎃 **Pumpkin Lurker** — Attacks when approached  
- 🍅 **Feral Tomatoes** — Detach and flee when threatened  
- 🌱 **Spreading Vine** — Infects nearby crops and terrain  

---

## 🛠️ Built With

- Unity (C#)
- Unity Input System
- Custom ScriptableObject-based crop system
